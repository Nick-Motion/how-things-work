# How Things Work

Interactive, hand-inked isometric figures of everyday machines, built with April Zhu's
[Colorfigures](https://april-zhu.com/colorfigures) skill. Drag to turn each one round,
flip on See-through to watch the mechanism, press the buttons.

Layout:
- `figures/<slug>/` — one figure: `figure.html` (source), `index.html` (built, self-contained), `meta.json`, `shots/`
- `site/` — the static listing site, deployed to Cloudflare
